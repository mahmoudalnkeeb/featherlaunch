# Contributing

FeatherLaunch is open source and maintained by one person, so **pull requests aren't accepted**
and will be closed without review. This keeps the project's direction and licensing simple.

**Issues are welcome.** Please report bugs and suggest features in
[GitHub Issues](https://github.com/mahmoudalnkeeb/featherlaunch/issues). For a bug, include:

- Your Windows or Linux version
- What you were doing when it went wrong
- `launcher.log` from the launcher's data folder (Settings, then Open under Data folder). It holds
  error messages only, no passwords or sign-in tokens.

To report a security problem, email support@mahmoudalnakeeb.com instead of opening a public issue.
